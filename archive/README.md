# Archive — inventory

Nothing in this repository is ever deleted. When a client, entity, or shared catalog item is retired, its folder or file is moved here unchanged so historical references and institutional memory stay intact.

To retire a client folder `clients/<slug>/`, move it to `archive/<slug>/` and add a one-line `ARCHIVED.md` inside giving the retirement date (`YYYY-MM-DD`), the operator email, and the reason.
