# system-administrator
## Display Name
System Administrator
## Purpose
Administers the application as a whole and updates, maintains, and expands its core processes and process points.
## Core Tasks
Maintain and extend processes, formats, skills, and scripts; configure shared system records; manage users, roles, and the application backlog; upgrade the application to the current template.
## Processes
None

- process-backlog
- setup-application
- upgrade-app
- update-user
- review-question-journal
- add-to-backlog
## Status
Active

# sales
## Display Name
Sales Representative
## Purpose
Works with customers to define their entitlements: the products and services they purchase.
## Core Tasks
Develop customer proposals from the product and service catalog; prepare and agree order forms with customers; record what each customer has purchased.
## Processes
None
## Skills
None
## Status
Active

# customer-success-manager
## Display Name
Customer Success Manager
## Purpose
Manages a customer on an ongoing basis and manages the delivery of the purchased services to them.
## Core Tasks
Onboard customers; keep client records current; resolve open issues; check delivery against the customer's order form; help the customer's team connect their systems.
## Processes
None

- setup-client
- review-open-issues
- setup-my-integrations
