# Clients — inventory

Each client (or primary business entity) has one isolated folder under `clients/<slug>/`, where `<slug>` is lowercase kebab-case. Filenames inside `clients/<slug>/` mirror the format contracts in `formats/`.

Use the `setup-client` skill (`/setup-client <path-to-handoff.md>`) to onboard a new client folder from a handoff file. Never create a client folder by hand outside `setup-client`.
